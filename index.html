About me

AC

I design and ship LLM-native services end to end — from hexagonal backend architecture and agent platforms through to the React interfaces people actually use. That range is the point: I can take an AI feature from system design all the way to the UI without handing it off. Most recently that meant an agent platform on hexagonal architecture with a provider-agnostic LLM layer, exposed over FastAPI and an MCP server, instrumented with OpenTelemetry and covered by unit, E2E and mutation tests.

It sits on a decade of production work — APIs, SDKs, data pipelines processing millions of records, and migrations like Heroku to AWS/Kubernetes. Agentic coding tools (Claude Code, OpenCode) are my default way of building, while I still own system design, testing and production tradeoffs myself. Frontend and product design round out the range when a feature needs taking all the way to the UI. Based in Tampere, Finland; originally from Bilbao, Spain. Finnish at B1.
